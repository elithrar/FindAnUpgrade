# Source and contract evidence

The classification input is a normalized factual extract of every `variants[].primaryStatus` and ID from ChatGPT Library item `libfile_7a7d39bd0d1c81919be5ccb96b9c6b9c`, `forever-verified-chart-data.json`, current version **1**, file `file_00000000994081f8a5a5dcbf8b5ac5cf`, collected 2026-10-14. The 56,251 source lines were read through Library; all reads reported version 1. Materialization was abandoned because the current Library Python helper requires `os.setxattr`, unavailable on this Windows Python runtime. The original Library file was not changed.

`data/primary-statuses.json` retains source identity/version and the **1,194 exact ID/status/title/zone records**. Its SHA-256 is `64017ae90fe4e16323044064b0ac5ba6102fba147446660fb1fd863eaf8e9ae5`. `tools/generate_data.py` reproducibly maps primary New/Updated/Unchanged to verifiedNew/verifiedUpdated/verifiedUnchanged; New is orange, Updated green and Unchanged/unknown plain. This yields **218 new IDs**, while the source's title-level chart has 202 new groups among 998 groups. No databaseNEW metadata is included.

Mixed-title evidence: Return the Statuette (286 unchanged, 98189 new); Rear Guard Patrol (356 unchanged, 99156 new); Crown of the Earth (921/928/929/933/934/935/7383 unchanged, 98046/98065 new); Twisted Hatred (932 updated, 98403 new); Arugal's Folly (422/423/99/424 unchanged, 98298 new).

Framework references were cloned read-only into ignored `references/`: [XPIsland](https://github.com/elithrar/XPIsland) at `739dd09e14e3c30dafec90ea743e48c00f6950ab`, and [AsTheCrowFlies](https://github.com/elithrar/AsTheCrowFlies) at `433dbe2892527d9afb198d15e3b7023ec828589b`. Both manifests specify interface 16001. Their AGENTS instructions, saved-data rules, namespace/module ownership, native controls, dark dialog chrome, gold labels, and checked optional Expressway/font fallback informed this implementation. Neither project was edited.

Client contracts use the XPIsland CI-pinned [Gethe/wow-ui-source revision](https://github.com/Gethe/wow-ui-source/tree/943764493e6b16d63ded3ab304150d1f05e58b57). Forever/Camelot follows the Mainline family quest XML/Lua paths in the UIPanels TOC. Mainline `QuestFramePanelTemplate` defines `Bg` and four Material regions plus SealMaterialBG. `QuestFrameDetailPanel_OnShow` applies material and invokes `QuestInfo_Display(QUEST_TEMPLATE_DETAIL, QuestDetailScrollChildFrame, ...)`; its caller uses `GetQuestID()` for offered quest identity. SimpleRegion API describes SetVertexColor as allowed with tainted arguments without protected-function marking, while GetVertexColor can return secret values or no values. All consumed colors/IDs are checked before arithmetic or comparison. The actual pinned material setter and detail renderer were executed offline with mocked native APIs.

The current Forever source snapshot is [735496de78ebd30ce816a0637982c556987f258c](https://github.com/Gethe/wow-ui-source/tree/735496de78ebd30ce816a0637982c556987f258c), version 1.60.1.70374. Matching quest-pin/hub, tooltip data and comparison contracts were inspected; the current native hub entry point and comparison manager execute offline with surrounding services mocked. `docs/client-contracts.json` records hashes for both source snapshots and read-only installed Questie 12.1.0 files. MONOLITH's `wow_classic_beta` installation has Forever 1.60.1.70374; its older `_forever_` launcher shell is 70245 and has no addon directory. No running-client build/API payload was observed.

Questie compatibility is tied to the actual installed `Modules/Tooltips/MapIconTooltip.lua`, `Modules/FramePool/QuestieFramePool.lua` and Camelot TOC. It reads rendered exact questOrder/npcAndObjectOrder IDs, positive marker alpha, fresh rebuild tokens and pooled identity; it writes no Questie data and supplies no duplicate pins. The optional QuestieDB adapter retains ATCF's Forever contract-3 provider boundary and reciprocal `questStarts`/`startedBy` evidence. No reward or association database is copied into this addon.

Client sources live only in ignored `.work/blizzard/` and `.work/current-api/`. The addon skill and matching references were read from the user's local skill mirror after the cloud reference links failed. No Blizzard source, extracted game artwork, font files, raw Library file, credentials or reference repository is included in the deliverable ZIPs. Runtime rendering and comparison remain native; their observed in-game behavior is pending.
