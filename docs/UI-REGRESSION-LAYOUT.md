# Live hover regression correction, 0.1.2

All six user images were materialized read-only from Library and inspected as pixels. They establish the failure of the installed 0.1.1 build: a fixed 400-unit outer panel, minimum-height empty status/evidence/footer rows, unconditional reward group space, non-native Expressway hover fonts, copper-number fallback and generic availability boilerplate. The supplied native-tooltip image is the visual reference. Passing earlier mocks did not establish native appearance.

## Correction

Each quest now uses the current native `TooltipBorderedFrameTemplate`, its NineSlice silver border, and native `GameTooltipHeaderText`/`GameTooltipText` font objects. The outer owner has no backdrop. Cards remain 320 logical units wide (304 when scrolling), but their heights follow wrapped content. New/Modified text is inline with the title; unchanged and unknown classifications reserve no line. Subtle orange/green changes affect the fill, preserving the native border. Available/log/turn-in or specific recorded chain facts take a line only when supported.

Known money and XP share one line. Money calls the current `C_CurrencyInfo.GetCoinTextureString(amount,12)`, with exact short-unit fallback. Missing/zero/unsupported fields, ordinary reputation and empty groups reserve no space. Guaranteed-only icons have no redundant label. Mixed guaranteed/choose-one groups retain explicit headings; guaranteed currencies are explicit when any choice exists. Icons remain 28 units with native rarity texture/color and exact native item/comparison rendering. The default count/header is removed; only overflowing stacks show a count and scroll hint. Their viewport is bounded to 320 logical units or the available screen space.

Placement captures the opening pointer and nearby original native tooltip. It prefers the nearest fitting side and freezes placement while cursor/source hovers change; reward refresh can refit content against the same opening coordinates. Source identity and native visibility are untouched. A narrow 1.25-second opening route protects travel when Questie hides its native tooltip on icon leave. This route starts on departure, is consumed at first stack entry, and cannot retain an abandoned stack indefinitely. Visible native transit checks the original owner, data object and readable semantic fields, header, rebuild token and rectangle. Item tooltips align to the inspected icon while retaining horizontal placement beside the stack; a narrow, bounded row corridor protects horizontal reward transit. Owned primary/comparison async deadlines, stale-generation guards and isolated comparison manager remain intact.

## Independent review

The native-layout reviewer identified four concrete remaining issues: Questie hiding the native tooltip broke transit; cross-card item transit was too short; in-place native tooltip identity changes survived object checks; guaranteed currency could follow a choose-one heading without a guaranteed label. Each was corrected with a focused regression. A subsequent update-flood probe found that same-item refresh reset the new row corridor deadline; refresh now preserves that deadline as well. The options and eligibility reviews are recorded separately. No review establishes live rendering or taint safety.

## Evidence and limits

`tests/stack_layout_test.lua` includes 16 meaningful scenarios for content height, omission, native fonts/template, exact tint, coin namespace, choice distinction, bounded scroll, cold-data timeout, completion filtering, scaled/frozen placement, original-native identity and transit, actual Questie hide sequence, consumed/expired opening route, inspected-button anchoring and bounded item-row transit. Existing async/comparison lifecycle suites remain required.

`python tools/render_hover_fixture.py` is an optional Windows layout fixture renderer; install Pillow only in `.work/pydeps` to run it. It executes shipped Lua with real Georgia substitute glyph metrics and approximates native border/icon art. The inspected output is `dist/hover-layout-fixture.png`, with explicit limitations in the paired JSON. Example measurements: two money/XP quests occupy 124 units rather than the old fixed 400; a mixed guaranteed/choice card occupies 158; an eight-card stack has a 320-unit viewport and a bounded scroll range. These are fixture measurements, not native pixels.
