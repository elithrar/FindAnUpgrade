# FindAnUpgrade 0.1.10

A fresh correctness review found and fixed disabled preview callbacks loading
character/quest state, repeated partial-item reads within a search, and unknown
usability/uniqueness remaining stale across deliberate queries. Pending metadata
is now shared within a query and retried later, with equipment/item revisions
and explicit invalidation taking precedence.

The patch also restores native contract coverage in release validation and fixes
receipt rollback and file-identity capture in the historical rename tools.
Font documentation now describes inheritance from the native tooltip family.
The approved design, controls, filters and item-level heuristic are unchanged.
