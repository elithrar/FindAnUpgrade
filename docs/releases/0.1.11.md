# FindAnUpgrade 0.1.11

The browser aligns search and dropdown borders, level fields and filter rows
on a shared grid. Guaranteed and choose-one rewards begin on the same icon
line, with group captions below. Locations use compact bullet separators and
minimum levels read `Req. lvl`. A native sorting-arrow control replaces the
previous icon, and a small query clear button appears while text is present.

Weapon searches such as gun, sword and wand use verified native item type and
subclass metadata, retaining character, usability and slot filtering. Copy
actions select text in the native EditBox flow for Ctrl+C; a direct addon
clipboard API is not verified on the supported Forever client.

Settings follows XPIsland's three-page dialog for Appearance, Behavior and
Search defaults. It adds native/SharedMedia font and owned panel-border choices
alongside existing scale controls. Saved usability, dungeon and relative level
defaults apply at the next search opening, while current session query, slot,
scope and sort remain separate. Existing preferences migrate to schema 4;
unsupported future settings remain preserved and read-only.

Source and offline checks cover layout, lifecycle and performance behavior.
Native rendering, physical input, Ctrl+C, comparisons, combat/taint and addon
coexistence still require observation in the client.
