# FindAnUpgrade 0.1.12

Quests and Shortlist share compact cards and the Options tab construction.
Stars save up to 20 exact quest IDs per character; saved quests remain visible
across zones and after completion. Each view retains its own query and scroll
position. Appearance resets preserve the shortlist and future save schemas
remain read-only. Native full-size gold fill sits beneath the same star outline.

Quest chain disclosure distinguishes all-of, any-of, count, optional and
alternative relationships, with bounded scrolling and concise evidence copy.
The bundled import preserves exact provenance and Forever-authored corrections;
inherited links remain nonblocking. Native active/log and gossip evidence take
precedence. This is incomplete source-backed coverage, not a complete server
availability database or a new Questie runtime dependency.

Native equipped comparisons now reconcile equipment, comparison settings and
cold metadata without unbounded retries. The native engine owns item pairing
and stat deltas; pointer transit includes the tooltip gap. `/fau slot ring`
and other supported slot names open Quests while retaining scope, query and sort.

Copy dialogs show Ctrl+C on Windows and Command+C on Mac. Native selected-text
copy input is preserved, then dismissal is deferred with owner, generation,
edit and focus guards. No clipboard-success acknowledgement is inferred.

Offline source, geometry and lifecycle checks do not establish native rendering,
physical copy timing, actual engine item comparisons, combat/taint or coexistence.
These remain specific live-client acceptance checks. No CurseForge publication.
