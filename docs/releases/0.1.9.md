# FindAnUpgrade 0.1.9

Biggest upgrade now uses usable slots and item-level gain as a small, transparent
heuristic. Removed the stat weights and scoring-style selector. Paired slots and
weapon hands retain equipment legality checks; missing levels, uncertain variants
or unsupported configurations remain unranked. Item level is a gear-level hint,
not a prediction of damage, healing or practical performance.

The compact sidebar, filters, native item hover, classification colors and
central Character state remain. High-resolution PNGs reconstruct the current
code using the earlier screenshots and verified source assets/data; they are
labelled mockups and do not establish native rendering.
